Gaia's Garden - Plant Database

Gaia's Garden is a database of common houseplants where users can find reliable information on popular houseplants, as well as images including (when available) the botanical illustrations. Users can save a list of the plants they have, love (favorites) or need (wishlist). Free to use — forever. Knowledge should be shared, not locked behind a paywall.

React · Flask · Python · REST APIs

Plant Database API

My first REST API, built to power Gaia's Garden. It runs a two-database design: an official plant catalog plus a community submission queue, where users submit their own plants and an admin approves vetted entries for migration to the official database.

Flask · Python

The Harvest Twins - Py Scrapers

Two scrapers that wrestle the wilds of Wikimedia's rate limits into submission. One searches for plant images, the other botanical plates. Both return the image/plate, author for credit and the license under which the images are used, then update the CSV with the scraped information.
